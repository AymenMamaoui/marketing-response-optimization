# Marketing Response Optimization & A/B Testing

## Business Problem

A company wants to maximize the return on its marketing budget by identifying customers who are most likely to respond to a campaign.

## Objective

Build an end-to-end Data Science pipeline that:

- Performs exploratory data analysis and feature engineering
- Predicts customer response probability
- Compares multiple machine learning models using stratified cross-validation
- Explains predictions using SHAP
- Estimates the business impact of targeted marketing through A/B testing
- Deploys a prediction service

## Pipeline

1. Problem definition
2. Data understanding
3. Exploratory data analysis
4. Feature engineering
5. Baseline modeling
6. Model comparison
7. Hyperparameter tuning
8. Model interpretation
9. A/B testing and business impact
10. Deployment

## Tech Stack

- Python
- pandas, NumPy
- scikit-learn
- XGBoost
- SHAP
- Matplotlib / Seaborn
- FastAPI
- Docker
